AVS03 Compiler Updater for 0.1.2

The standalone updater adds compiler-only update checks to existing 0.1.2 installations. It does not update the game or change game files, APKs, or saves.

Linux x86-64:
1. Download AVS03-Compiler-Updater-Linux-x86_64.zip and extract it.
2. Copy AVS03-Compiler-Updater into the folder containing AVS03-Android-Builder or AVS03-Android-Builder-SDK-Downloader.
3. Close the compiler and run AVS03-Compiler-Updater.

Windows source builder:
1. Download AVS03-Compiler-Updater-Windows-Source.zip.
2. Close the compiler and extract the ZIP into the folder containing avs03_wrapper_builder.py, merging the files.
3. Run Run-Compiler-Updater.bat. Python 3 with Tkinter is required.

The updater selects the OS and edition package, verifies the published SHA-256 digest, and asks for your approval before downloading or installing. Nothing is downloaded or installed without your approval. It then starts the compiler. Keep the compiler in a folder writable by your account. It does not target game files, APKs, saves, tool caches, or AVS03 user data.
