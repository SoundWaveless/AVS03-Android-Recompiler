AVS03 Android Recompiler 0.1.3

This release bundles the compiler updater with all four OS and SDK-edition packages.

Changes:
- The updater runs before the compiler when launched with Run-Builder and can also be started from Check for Compiler Updates. It chooses the matching OS/edition package, verifies its SHA-256 digest, and asks for explicit user approval before downloading or installing; declining leaves the current compiler unchanged. It updates compiler files only; game files, APKs, and saves are not part of the update.
- The Linux packages contain the standalone AVS03-Compiler-Updater executable. Windows source packages include the Python updater and Run-Compiler-Updater.bat.
- Added a document icon beside the compiler title. It opens the bundled README inside a scrollable window titled “AVS03 Compiler README.”
- Improved updater window scaling. Its message text follows the available width, buttons switch to a vertical layout when needed, and the window can be resized vertically.
- Refreshed the packaged documentation, including instructions for 0.1.2 users adding the standalone updater and descriptions of APK update/save-transfer behavior.

Existing 0.1.2 users can install the separate updater assets from the v0.1.2 release and use them to obtain the matching 0.1.3 package. See docs/UPDATER.md.

The builder continues to require the user's own legal game installation. This fan project is not affiliated with the game developer, publisher, or Steam and does not distribute game files.
